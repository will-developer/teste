# Avalia+

**Avalia+** é um Sistema de Gerenciamento de Turmas e Alunos, projetado para simplificar a vida de educadores. Com uma interface intuitiva e moderna, permite a organização de turmas, o gerenciamento de alunos e o controle de notas de forma eficiente.

## 📜 Descrição do Projeto

Este projeto foi desenvolvido como uma solução para educadores gerenciarem suas turmas de forma digital. A aplicação permite criar, visualizar, editar e remover turmas, tudo persistido localmente no navegador para uma experiência de usuário contínua. Construído com as tecnologias mais recentes do ecossistema React, o Avalia+ é rápido, responsivo e fácil de usar.

## ✨ Funcionalidades Principais

  * **Gestão de Turmas:** Crie, edite e remova turmas com facilidade.
  * **Interface Intuitiva:** Design limpo e moderno construído com Material-UI.
  * **Persistência de Dados:** Suas turmas são salvas localmente no seu navegador, sem necessidade de um banco de dados.
  * **Design Responsivo:** Acesse e gerencie suas turmas em qualquer dispositivo.
  * **Busca Rápida:** Encontre turmas rapidamente com a funcionalidade de pesquisa integrada.
  * **Validação de Formulários:** Garante a integridade dos dados com validação em tempo real usando Zod.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

  * **Framework:** [Next.js](https://nextjs.org/)
  * **Biblioteca UI:** [React](https://react.dev/)
  * **Linguagem:** [TypeScript](https://www.typescriptlang.org/)
  * **Componentes UI:** [Material-UI (MUI)](https://mui.com/)
  * **Estilização:** [Sass](https://sass-lang.com/) / CSS Modules
  * **Validação de Esquemas:** [Zod](https://zod.dev/)
  * **Gerenciamento de Formulários:** [React Hook Form](https://react-hook-form.com/)
  * **Testes:** [Jest](https://jestjs.io/) e [React Testing Library](https://testing-library.com/)

## 🚀 Como Começar

Siga os passos abaixo para executar o projeto em seu ambiente local.

### Pré-requisitos

  * [Node.js](https://nodejs.org/) (versão 20 ou superior)
  * [Yarn](https://yarnpkg.com/) ou [npm](https://www.npmjs.com/)

### Instalação

1.  Clone o repositório para a sua máquina local:
    ```bash
    git clone <URL_DO_REPOSITORIO>
    ```
2.  Navegue até o diretório do projeto:
    ```bash
    cd Nova pasta
    ```
3.  Instale as dependências necessárias:
    ```bash
    npm install
    ```
    ou
    ```bash
    yarn install
    ```

### Executando a Aplicação

Para iniciar o servidor de desenvolvimento, execute o comando:

```bash
npm run dev
```

ou

```bash
yarn dev
```

Abra [http://localhost:3000](https://www.google.com/search?q=http://localhost:3000) em seu navegador para ver a aplicação em funcionamento.

## 📜 Scripts Disponíveis

No diretório do projeto, você pode executar:

  * `npm run dev`: Inicia a aplicação em modo de desenvolvimento.
  * `npm run build`: Compila a aplicação para produção.
  * `npm run start`: Inicia um servidor de produção.
  * `npm run lint`: Executa o linter para verificar erros de código.
  * `npm run test`: Executa os testes unitários e de componente.
